# hub-ui-preview

Static preview of UI mockups and the design library for an in-development system.

**Generated.** The source of truth lives in a private repository; every file here is
built by a tool and overwritten on each publish. Do not edit anything here.

- `index.html` - the board: every screen with its status.
- `m/` - the screens themselves, as standalone HTML pages.
- `llm/` - the same screens as plain text, for reading without rendering.

Screens are demonstrations only: no system connection, no real data, no writes.
A screen that is not marked approved is not a design contract.
